A smart, responsive chatbot interface created as part of a Year 10 Data Science project at Churchie (Anglican Church Grammar School).
ChurchieBot is designed to assist students with campus-related queries, including:

📅 Canteen menus with budget filtering

🧭 Navigation directions between buildings

🏀 Sport training schedules

📚 Subject selection help for Years 7–12

⏱️ Utility features like current time, date, and simple math operations

🛠 Features
Smooth toggle and expand/collapse chat UI

Custom typing animation for natural bot feedback

Drag to resize the chat window

Support for dynamic image background uploads

Special commands like:

__UPLOAD_CHAT_BG__ → Upload chat background

__RESET_CHAT_BG__ → Reset background

__MAKE_FULLSCREEN__ → Fullscreen chat

___DELETE_CHAT____ → Clear messages

__RESET_CHAT_SIZE__ → Restore default size

📁 Project Structure
index.html → Main page with embedded chatbot UI

responses.js → Logic engine for bot responses and category handling

Nexus Page to Show.png → Background image (default)
